# Use PostgreSQL for Nova investigation cases

**Decision ID:** decision_d006  
**Project:** Project Nova  
**Technology:** PostgreSQL  
**Proposed by:** Isaac Brown  
**Approved by:** David Kim  
**Date:** 2026-05-07

## Decision
Use PostgreSQL for Nova investigation cases.

## Rationale
Investigation cases required transactional updates, auditability, and flexible analyst queries.

## Alternatives considered
