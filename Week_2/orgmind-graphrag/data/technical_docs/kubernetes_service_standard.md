# Kubernetes Service Deployment Standard

Kubernetes is the preferred deployment platform for continuously running services that need controlled rollouts, autoscaling, and standardized health checks.

Hannah Brooks owns the production-readiness checklist. Project Atlas runs ranking services on Kubernetes. Project Phoenix also uses Kubernetes for recommendation serving. Bob Singh and Hannah Brooks both have hands-on Kubernetes experience and both worked on Project Phoenix.
